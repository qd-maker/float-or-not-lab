# Day5-Day7 Hackathon 计划

项目方向：继续深入「浮不浮实验室」，把一次性科普工具升级为有学习反馈的浮力训练闭环。

核心路径：

```text
理解概念 → 公式计算 → 完成题目 → 诊断错因 → 针对性练习 → 查看学习进步
```

## 为什么继续原项目

- 前四天已经完成可运行、可部署的基础产品，继续迭代能把时间用在真实用户价值上，而不是重复搭建项目骨架。
- 当前产品已经能解释和判题，但学生做完后缺少长期反馈，仍有明确可验证的问题可以解决。
- Day5-Day7 的新增能力能与原有概念实验、公式实验室、题库和 AI 小老师组成完整学习闭环。

## Day5：学习数据与错题订正

### 目标

让学生知道自己做了多少题、哪里薄弱，以及哪些错题还没有订正。

### 计划产出

- 将学习记录升级为逐题记录，保存提交次数、正确次数、最近结果和订正状态。
- 增加学习情况面板：题库进度、提交次数、正确率、待订正数量。
- 根据作答数据给出薄弱题型和掌握较好题型。
- 增加错题本，曾经答错的题可以集中重练。
- 错题答对后自动显示「已订正」。
- 使用 LocalStorage 持久化，并兼容旧版统计数据。

### 验收标准

- 刷新页面后记录仍然存在。
- 错题能进入错题本，重新答对后状态改变。
- 空错题本有清楚的引导文案。
- 前端生产构建和后端回归测试通过。

## Day6：AI 针对性变式题

### 目标

让 AI 从「解释错误」进一步升级为「根据当前错因出一道同类题」，实现讲完马上练。

### 计划产出

- 先在 API Contract 中定义变式题请求、响应和错误处理。
- 新增 `POST /api/ai/generate-variant`。
- 输入原题、学生答案、正确答案、错因和知识点。
- AI 使用结构化输出生成一道初中浮力变式题。
- 后端用 Pydantic 校验题目、选项、答案和解析。
- AI 不可用或输出不合格时回退到本地变式题。
- 前端增加「再练一道同类题」，并将结果计入学习记录。

### 验收标准

- 生成题只涉及初中浮力。
- 选择题只有一个合法正确答案。
- AI 异常时主流程仍可演示。
- 变式题可作答、判题、查看解析并记录结果。

## Day7：最终验证与提交

### 目标

停止扩功能，集中完成线上回归、演示证据和七日复盘。

### 计划产出

- 完成核心学习路径回归测试。
- 检查桌面端和移动端布局、Loading、错误输入和 AI 失败降级。
- 更新线上版本并验证域名访问。
- 准备功能截图和 2-4 分钟演示录屏。
- 完成 Day1-Day7 每日五问。
- 完成最终复盘：AI 帮助、AI 错误、如果重来会如何调整。
- 回答流程设计的三个问题。

### 验收标准

- README、在线 Demo、七日小结和最终复盘都能从仓库直接找到。
- 演示路径没有阻断性问题。
- 仓库不包含密钥、日志或临时构建文件。

## 范围控制

三天内不增加登录注册、数据库、教师后台、多学科题库和复杂 RAG。重点完成：

> 做题 → 发现错误 → AI 解释 → 同类强化 → 查看进步。
