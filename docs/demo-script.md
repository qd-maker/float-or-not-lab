# 浮不浮实验室最终演示脚本

建议时长：3 到 5 分钟
在线 Demo：[https://float.heyqi.xyz/](https://float.heyqi.xyz/)

## 1. 开场，20 秒

大家好，这是我七天内完成的「浮不浮实验室」。

它不是完整物理课程，只围绕初中物理的一个知识点：浮力。目标是让学生从看懂物体为什么会上浮或下沉，走到能完成真实浮力题，并针对自己的错误继续练习。

整个学习路径是：

```text
概念实验 → 公式计算 → 真实题目 → 错因诊断
→ AI 讲解 → 同类强化 → 学习反馈
```

## 2. 概念实验，40 秒

输入：

- 物体重量 `8 N`。
- 完全浸没时排开水的重量 `10 N`。

点击「开始实验」。

讲解：

> 页面比较的是物体刚完全浸没时的最大浮力和重力。排开水的重量更大，最大浮力足够托住物体，所以物体会上浮。水槽位置和两个力的箭头会同步变化。

再改成：

- 物体重量 `10 N`。
- 完全浸没时排开水的重量 `6 N`。

此时浮力小于重力，物体下沉。

补充一句：物体最终漂浮稳定后，浮力会重新等于物体重力。

## 3. 公式实验室，40 秒

选择「阿基米德原理」，输入：

- 水的密度 `1000 kg/m³`。
- 排开体积 `0.003 m³`。
- `g = 10 N/kg`。

点击「计算浮力」。

页面显示完整过程：

```text
F浮 = ρ液 g V排
F浮 = 1000 × 10 × 0.003
F浮 = 30 N
```

讲解：

> 这里不只给最终数字，而是让学生看到选公式、代入和得出结果三个步骤。切换称重法或漂浮平衡时，输入项也会跟着变化。

## 4. 故意答错并查看动态错因，50 秒

进入「真实题目训练」，选择第一道阿基米德公式题，把正确答案 `30 N` 故意答成 `3`。

页面会显示：

- 标准答案。
- 分步解析。
- 根据学生答案生成的具体错因。

讲解：

> 学生答成 3 时，系统会识别为可能漏乘了重力加速度 `g`。这部分使用确定性规则，不让 AI 猜学生是否答对。

同时可以看到学习面板发生变化：

- 提交次数增加。
- 正确率更新。
- 当前题进入错题本并显示「待订正」。

## 5. AI 小老师，50 秒

点击「让 AI 针对我的错误讲一遍」。

讲解：

> 后端会把题干、全部选项、学生答案、正确答案、标准解析和错因一起传入，要求 AI 针对具体错误讲解。回答通过 SSE 逐段返回，并由 Markdown 和 KaTeX 渲染数学公式。

也可以点击快捷追问，例如：

- 为什么这个答案不对？
- 请提示这道题的易错点。
- 能换个生活中的例子解释吗？

如果 AI 服务不可用，页面会自动使用本地讲解，基础流程不会中断。

## 6. 同类强化题，40 秒

在错因区域点击「再练一道同类题」。

讲解：

> AI 会根据当前知识点和错因生成一道同难度变式题。生成内容不能直接展示，后端会先检查题型、选项、答案和解析。判题仍由确定性代码完成；任何环节失败都会切换到本地变式题。

完成强化题后，学习面板会统计强化次数，但基础题进度不会出现 `11/10`。

## 7. 错题订正，30 秒

进入「错题本」，重新完成刚才答错的题。

答对后状态从「待订正」变成「已订正」。刷新页面后记录仍然存在，因为学习数据保存在 LocalStorage。

## 8. 技术与 AI 协作总结，40 秒

项目技术栈：

- React + TypeScript + Vite。
- FastAPI + Pydantic。
- SSE + Markdown + KaTeX。
- OpenAI-compatible API。
- Nginx + Uvicorn，仓库包含 Docker Compose 配置。

七天里 AI 最主要的作用是快速生成方案和代码初稿、辅助 Debug 和补充测试。但 AI 也在物理概念、统计口径、具体选项解释和前端布局上出过错。

最终采用的原则是：

> 公式、标准答案和判题由确定性代码负责；AI 负责解释和生成候选内容；生成结果必须经过校验并且随时可以降级。

## 9. 结束语，10 秒

学生最终不只是看到「上浮」两个字，而是完成了一条可以闭环的学习路径：看见现象、理解公式、做题、知道为什么错、再练一道，并看到自己的进步。
