# Day4 演示脚本

目标：用 3 到 5 分钟讲清楚这个 demo 做了什么、为什么这样做、AI 在哪里帮忙。

## 1. 开场：项目定位

大家好，这是我这四天做的「浮不浮实验室」。

它不是完整物理课程，只围绕初中物理里的一个知识点：浮力。

我想让学生通过这个网页明白三件事：

1. 水会给物体一个向上的力，这个力叫浮力。
2. 能不能浮起来，不是只看物体重不重，而是看浮力能不能托住重力。
3. 初中浮力题常见方法包括阿基米德公式、称重法和漂浮平衡。

## 2. 第一段演示：概念实验区

操作：

- 输入物体重量 `8 N`。
- 输入完全浸没时排开水重量 `10 N`。
- 点击「开始实验」。

讲解：

这里比较的是物体刚完全浸没时的最大浮力。

如果完全浸没时排开水的重量大于物体重力，说明最大浮力足够大，物体会上浮。

页面里水槽的物体会露出水面，左边浮力箭头也更长。

再切换一个下沉例子：

- 物体重量 `10 N`。
- 完全浸没时排开水重量 `6 N`。

这时浮力小于重力，物体会沉到底部。

## 3. 第二段演示：公式实验室

操作一：阿基米德原理。

- 选择「阿基米德原理」。
- 输入水的密度 `1000 kg/m³`。
- 输入排开体积 `0.003 m³`。
- `g` 取 `10 N/kg`。
- 点击「计算浮力」。

讲解：

页面不会只给答案，而是显示：

```text
F浮 = ρ液 g V排
F浮 = 1000 × 10 × 0.003
F浮 = 30 N
```

这样学生能看到代入过程。

操作二：称重法。

- 选择「称重法」。
- 空气中物体重力 `12 N`。
- 水中测力计示数 `7 N`。

结果是：

```text
F浮 = G物 - F示 = 12 - 7 = 5 N
```

## 4. 第三段演示：真实题目训练

操作：

- 进入「真实题目训练」。
- 选择一道题。
- 故意答错，例如阿基米德题填 `3`。

讲解：

页面会显示：

- 答错提示。
- 标准答案。
- 分步解析。
- 动态错因提示。

如果学生把 `30 N` 答成 `3`，系统会提示可能漏乘了 `g`，而不是只给一个固定错误说明。

提交后主按钮会变成「已提交，先看下方解析」，让学生先读解析，再点击底部「看完解析，下一题」。

## 5. 第四段演示：AI 小老师

操作：

- 答错后点击「让 AI 针对我的错误讲一遍」。
- 或者在右侧输入框输入：

```text
为什么漂浮时浮力等于重力？
```

讲解：

AI 小老师不是开放聊天机器人，它被限制为只回答物理题、物理概念、物理计算和物理实验现象。

它的回答使用 Server-Sent Events 流式输出，所以长答案会逐段显示。

如果没有配置 AI key，系统会自动返回本地模板解释，基础 demo 不会挂。

## 6. 技术取舍说明

这四天我做了几个取舍：

1. 不做完整课程，只做浮力一个知识点，保证范围可控。
2. 不引入复杂物理引擎，用规则计算和 CSS 动画表达核心概念。
3. 题库先内置在代码里，不接数据库，保证 demo 快速稳定。
4. AI 只做错因解释和受限追问，不替代标准解析。
5. Docker 部署优先，前端用 Nginx 静态托管，后端用 FastAPI。

## 7. 结束语

最后学生应该能理解：

- 物体在水中受到向上的浮力。
- 浮力够大就能托住物体。
- 漂浮时浮力等于重力。
- 船能浮起来，是因为它排开了足够多的水，获得了足够大的浮力。
