# 产品计划：浮不浮实验室

## 一句话介绍

一个网页实验室，让初中生通过「概念动画、公式计算、真实题目训练」理解浮力。

项目只围绕一个知识点：

> 物体为什么会浮起来，以及如何计算浮力。

## 为什么选这个知识点

浮力是初中物理里很适合做成交互工具的知识点。它有明确的输入、明确的结果，也可以用水槽、物体、箭头动画表现出来。

Day1 做完最小 demo 后发现，如果只让学生输入「物体重量」和「排开水重量」判断上浮、悬浮、下沉，工具会偏单调，也不够贴近真实初中学习。

所以后续方向调整为：

```text
概念演示 + 公式计算 + 真实题目训练
```

这样仍然不做完整课程，只围绕浮力这个知识点，但学生能真正练会常见题型。

## 初中浮力学习范围

本项目后续覆盖初中常见浮力内容，但不扩展到高中复杂流体力学。

### 1. 浮力概念

```text
浸在液体中的物体会受到液体对它向上的力，这个力叫浮力。
```

### 2. 阿基米德原理

```text
F浮 = G排
```

通俗说法：

> 物体排开多少水，水就能给它多大的托力。

### 3. 阿基米德计算公式

```text
F浮 = ρ液 g V排
```

字段含义：

| 符号 | 含义 | 常见单位 |
| --- | --- | --- |
| F浮 | 浮力 | N |
| ρ液 | 液体密度 | kg/m³ |
| g | 重力常数 | N/kg |
| V排 | 排开液体体积 | m³ |

### 4. 称重法求浮力

```text
F浮 = G物 - F示
```

含义：

- G物：物体在空气中的重力。
- F示：物体浸入液体后弹簧测力计的示数。
- 两者差值就是浮力。

### 5. 浮沉条件

```text
F浮 > G物：上浮
F浮 = G物：悬浮或漂浮时平衡
F浮 < G物：下沉
```

## 用户能学会什么

学生用完后，至少能理解：

1. 物体在水中会受到一个向上的力，这个力叫浮力。
2. 浮力够大，物体就会上浮。
3. 浮力不够，物体就会下沉。
4. 浮力大小可以用排开液体的重力来计算。
5. 看到弹簧测力计示数变小，可以用称重法求浮力。
6. 船能浮起来，不是因为它轻，而是因为它排开了很多水，获得了足够大的浮力。

## MVP 功能

### Day1：概念原型

- 确定选题和学习目标。
- 完成 API Contract。
- 建立前后端项目骨架。
- 建立每日进度文档。
- 做出第一版水槽动画和浮沉判断。

### Day2：公式实验室

新增三个计算模式：

1. 阿基米德原理模式：`F浮 = ρ液 g V排`
2. 称重法模式：`F浮 = G物 - F示`
3. 漂浮平衡模式：漂浮时 `F浮 = G物`

每个模式都要输出：

- 输入数据。
- 使用公式。
- 代入过程。
- 计算结果。
- 和动画联动的浮沉判断。

### Day3：真题训练模式

新增初中真实题型训练：

1. 直接判断浮沉。
2. 称重法求浮力。
3. 阿基米德公式计算。
4. 漂浮问题。
5. 生活应用题，例如轮船、潜水艇、盐水浮鸡蛋。

每道题要包含：

- 题干。
- 答案输入或选择。
- 正误判断。
- 分步解析。
- 错因提示。

### Day4：工程化和演示

- Docker 化。
- 部署到服务器。
- 完成 README 和演示说明。
- 整理项目总结。
- 整理四天 AI 协作记录。

## 交互设计

用户看到一个实验台页面：

1. 先看水槽动画，理解浮力和重力的关系。
2. 再进入公式实验室，选择不同计算方法。
3. 最后进入题目训练，用真实题型检验是否掌握。

## 技术取舍

### 为什么 Day1 先做简单 demo

Day1 的目标是快速验证核心交互：输入、计算、动画反馈。虽然它偏简单，但可以作为后续公式和题目的基础。

### 为什么 Day2 开始加公式

初中真实学习不只是判断浮沉，还需要会用公式求浮力。因此 Day2 要加入公式模式，让项目从「演示工具」升级成「学习工具」。

### 为什么 Day3 加题库

学生真正掌握知识点，不能只看演示，还要做题。题库可以体现 AI 协作的价值：AI 生成题目，我负责筛选、改写、校验解析是否符合初中物理范围。

### 为什么暂时不使用完整物理引擎

这个项目目标是理解浮力知识点，不是做真实流体仿真。完整物理引擎会增加开发成本，也可能让注意力从概念理解转移到动画效果上。

所以 MVP 使用规则计算 + CSS / SVG 动画。

### 为什么保留后端

即使部分计算前端也能完成，后端仍然有价值：

- 练习完整前后端工程结构。
- 后续可以接入数据库记录做题结果。
- 后续可以接入 AI 生成解释或错因分析。
- 更适合部署和简历展示。
