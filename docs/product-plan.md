# 四天开发计划：浮不浮实验室

项目名称：浮不浮实验室 Float or Not Lab
项目方向：初中物理浮力科普小工具
周期：Day1 到 Day4

## 项目目标

做一个网页小工具，让小学高年级和初中生通过「概念演示、公式计算、真实题目训练」理解浮力。

核心知识点只围绕浮力展开：

> 物体能不能浮起来，不是只看它重不重，而是看它受到的浮力能不能托住它。

## 四天总体路线

| 天数 | 阶段目标 | 当天主要产出 |
| --- | --- | --- |
| Day1 | 定方向 + 搭骨架 | 确定选题、学习目标、API Contract、前后端项目骨架、第一版概念 demo、每日进度文档 |
| Day2 | 公式实验室 | 加入阿基米德公式、称重法、漂浮平衡，输出分步计算过程 |
| Day3 | 真实题目训练 | 加入初中浮力题库、答题判断、分步解析、错因提示 |
| Day4 | 部署和总结 | Docker 部署、README 完善、线上 demo、演示话术、四天总结 |

---

## Day1：定方向 + 搭骨架

### 目标

先做出一个能跑起来的最小原型，验证这个选题能不能做成可交互网页工具。

### 计划完成

- 确定知识点：初中物理浮力。
- 确定项目名：浮不浮实验室。
- 明确目标用户：小学高年级和初中生。
- 明确核心学习目标：理解浮力能不能托住物体。
- 写 API Contract。
- 搭建 FastAPI 后端骨架。
- 搭建 React + Vite 前端骨架。
- 实现第一版输入和判断：上浮、悬浮、下沉。
- 做第一版水槽动画和浮力 / 重力箭头。
- 建立 GitHub 仓库和每日进度文档。

### 验收标准

- 本地能启动前端页面。
- 后端有健康检查接口。
- 后端有浮沉判断接口。
- 页面能输入物体重量和排开水重量。
- 每日进度文档能给老板查看。

---

## Day2：公式实验室

### 目标

把项目从「看懂浮不浮」升级成「会算基础浮力题」。

### 计划完成

- 新增公式实验室模块。
- 支持阿基米德原理计算：`F浮 = ρ液 g V排`。
- 支持称重法计算：`F浮 = G物 - F示`。
- 支持漂浮平衡解释：漂浮时 `F浮 = G物`。
- 每种计算都展示：
  - 使用公式。
  - 代入过程。
  - 最终结果。
  - 一句学生能听懂的解释。
- 后端新增公式计算接口。
- 前端新增公式输入区。
- 补充后端测试。
- 更新 Day2 每日进度。

### 验收标准

- 学生输入密度、排开体积、g 后能算出浮力。
- 学生输入空气中重力和测力计示数后能用称重法求浮力。
- 页面不是只给答案，而是显示分步计算过程。

---

## Day3：真实题目训练

### 目标

让学生通过真实初中题型巩固浮力知识点。

### 计划完成

- 建立初中浮力题库。
- 至少覆盖五类题型：
  - 直接判断浮沉。
  - 称重法求浮力。
  - 阿基米德公式计算。
  - 漂浮问题。
  - 生活应用题，例如轮船、潜水艇、盐水浮鸡蛋。
- 前端增加题目训练区。
- 支持选择题或填空题提交。
- 提交后显示正误。
- 显示正确答案。
- 显示分步解析。
- 显示常见错因提示。
- 更新 Day3 每日进度。

### 验收标准

- 至少有 8 到 10 道可练习题。
- 每道题都有解析。
- 答错时能看到错因提示。
- 题目范围不超出初中浮力基础内容。

---

## Day4：部署和总结

### 目标

把项目整理成可演示、可部署、可写进简历的 MVP。

### 计划完成

- 完善 Dockerfile 和 docker-compose.yml。
- 整理环境变量配置。
- 部署到服务器。
- 完善 README：
  - 项目介绍。
  - 功能说明。
  - 本地运行方法。
  - Docker 运行方法。
  - API 说明。
- 整理四天每日进度文档。
- 准备演示流程：
  - 先演示概念实验。
  - 再演示公式计算。
  - 最后演示题目训练。
- 整理项目取舍：为什么不做完整课程，为什么不做复杂物理引擎，为什么保留后端。

### 验收标准

- 项目可以通过网页访问。
- README 能让别人跑起来。
- GitHub 有连续提交记录。
- 每天都有五问进度反馈。
- 最终 demo 能清楚讲明白浮力这个知识点。
